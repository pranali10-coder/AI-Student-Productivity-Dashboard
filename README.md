# 🤖 AI Powered Smart Student Productivity Dashboard

🚀 A modern Full Stack Web Application developed to manage student tasks, attendance, and productivity using an interactive dashboard with AI-inspired analytics.

The project provides a smart digital platform where users can add, update, manage, and monitor student activities efficiently through a clean and responsive interface. It combines frontend design, backend processing, database connectivity, and analytical insights into a single system. ✨

---

## ✨ Key Features

✅ CRUD Operations (Create, Read, Update, Delete)  
✅ Student Task & Attendance Management  
✅ AI Productivity Score Analysis 🤖  
✅ Smart Recommendations System  
✅ Pending Task & Completion Analytics 📊  
✅ Most Active Student Detection 🏆  
✅ Search & Filter Functionality 🔍  
✅ Responsive Glassmorphism UI  
✅ Dynamic Dashboard Cards  
✅ Form Validation & Error Handling
